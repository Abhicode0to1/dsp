## FEATURES NEEDED:

### 1. CUSTOMER FEATURES (End Users)
- Login with email/password
- Dashboard showing their plan, usage (tickets/chats/calls), billing
- Create support tickets with file attachments
- View all tickets, reply to agent messages (real-time updates)
- Live chat with support agents (real-time messaging + file upload)
- Request phone calls with agents (virtual numbers, anonymized)
- View chat & call history
- Rate satisfaction (CSAT 1-5 stars)
- View & download invoices
- Upgrade plan (with Razorpay payment)
- View usage bars (tickets used/limit, chats used/limit, calls used/limit)

### 2. AGENT FEATURES (Support Team)
- Login with email/password
- Dashboard showing assigned tickets, waiting chats, active calls
- View & reply to tickets
- Accept & manage live chats (real-time)
- Answer incoming calls
- Transfer chat to another agent
- Add internal notes (not visible to customer)
- View customer history & past interactions
- Create canned responses (macro templates)
- View personal performance (CSAT, SLA%, response time)

### 3. ADMIN FEATURES (Business Owner)
- Login with email/password
- Dashboard: total customers, revenue, ticket SLA health, chat/call volume
- Manage customers (list, view detail, update plan)
- Manage agents (create, activate/deactivate, assign skills)
- Configure support plans (Free, Basic, Moderate, Premium)
- View all tickets, chats, calls (across all customers)
- Generate reports (revenue, usage, agent performance)
- View audit log (who did what, when)
- App settings (CSAT threshold, email settings, etc.)
- Usage monitoring (find customers exceeding their limits)

### 4. PLAN TIERS (Subscription Models):

**Free Plan:**
- Unlimited email tickets
- No live chat
- No phone calls
- No priority support

**Basic Plan:**
- 5 tickets/month
- Live chat enabled
- No phone calls
- Normal priority

**Moderate Plan:**
- 10 tickets/month
- Live chat enabled
- 5 calls/month
- Medium priority

**Premium Plan:**
- 20 tickets/month
- Live chat enabled
- 10 calls/month
- High priority

### 5. INTEGRATIONS NEEDED:
- Razorpay (payment processing for plan upgrades, invoices)
- SendGrid or email service (transactional emails)
- Real-time chat (Socket.io - not REST API)
- File uploads (max 25MB per file)

==============================================

## TECHNICAL REQUIREMENTS:

### Frontend (Web Application for all users):
- React 18
- Tailwind CSS (styling)
- Real-time updates (Socket.io)
- Responsive design (works on mobile + desktop)
- Login/authentication

### Backend (Server & APIs):
- Node.js + Express.js
- 80+ REST API endpoints
- Socket.io for real-time chat/notifications
- JWT authentication
- MySQL database
- Razorpay integration
- Email integration (SendGrid)

### Database:
- MySQL 8.0+
- 19 tables (users, customers, tickets, chats, calls, invoices, plans, etc.)
- Audit logging (track all actions)

### Deployment:
- Can be hosted on AWS, DigitalOcean, or Heroku
- HTTPS (SSL certificate)
- Automated backups
- Production-ready
